The ```percentage``` command shows the distribution of languages and file types in a repository.


```bash
ctx3 percentage <path>
```

output sample:
```bash
┌── File Percentages:
├── toml         4.7% ██
└── rs          95.3% ███████████████████████████████████████████████
```
the default path is the curent dir but you can pass your desired path as well.
